### 🔹 [Retail_Performance_Dashboard](https://github.com/leaHadj/Retail_Performance_Dashboard)

### 🔹 [prediction_no2_new_delhi](https://github.com/leaHadj/prediction_no2_new_delhi)

A predictive modeling project aiming to forecast **NO₂ concentration +6 hours ahead** using pollution and meteorological data.

- Data cleaning and merging (pollution + weather datasets)
- Feature engineering (lag features, temporal variables)
- Model comparison: Linear Regression vs Random Forest
- Best performance achieved with Random Forest (R² ≈ 0.72)
- Deployment of a prototype using **Streamlit** for interactive predictions

This project combines environmental data science with practical model deployment.

**Tech stack:** Python · Pandas · NumPy · Scikit-learn · Matplotlib · Streamlit
